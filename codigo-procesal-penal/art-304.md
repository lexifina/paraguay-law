# Artículo 304. MEDIDAS CAUTELARES
El acta de imputación no implicará necesariamente la aplicación de una medida cautelar. El fiscal cuando lo considera pertinente, requerirá al juez penal la aplicación de cualquiera de las medidas cautelares dispuestas, de conformidad a las reglas de este código.
Sin embargo, no se podrá solicitar ni aplicar una medida cautelar si no existe previamente un acta de imputación fundada.

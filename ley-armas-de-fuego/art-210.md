# Artículo 210
Disponer que a los efectos de la presente ley se entenderá por:
a. Número CAS: Chemical Abstract Service. El número de registro CAS es una identificación numérica única para productos químicos la cual se integra a una base de datos con el fin de evitar asignar distintos nombres para un mismo compuesto.
b. Número ONU: identidades ONU o códigos UN (en inglés, UN number). Número de identificación de las sustancias químicas peligrosas asignado por la Organización de las Naciones Unidas.
